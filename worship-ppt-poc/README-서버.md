# 이 Mac의 임시 서버

현재 앱은 이 Mac의 MySQL 데이터베이스 `worship_local`에 연결합니다. 기존 `local-songs.sqlite3`은 **이전 시점의 백업**이며 이후 앱에서 수정한 내용과 자동 동기화되지 않습니다. 기존 33곡, 별칭 26건, 요청 대기열 및 사용 권한 상태를 이전하고 전체 필드가 일치하는지 확인했습니다.

Finder에서 `찬양 PPT 만들기.app`을 열면 전용 MySQL이 실행 중인지 확인하고, 필요하면 시작한 뒤 웹 화면을 엽니다. Mac의 전원이 꺼지거나 잠들면 서버도 이용할 수 없습니다. Mac을 켠 다음 앱을 다시 여세요. 현재는 웹과 DB가 127.0.0.1에만 열려 있어 이 Mac에서만 사용할 수 있습니다. 다른 PC 접속은 계정 인증과 네트워크 설정을 추가한 뒤 구성해야 합니다.

DB 데이터와 접속 정보는 `.server/`에 있으며 Git에 포함하지 않습니다. 비밀번호 설정 파일은 소유자만 읽을 수 있도록 만들었습니다. `local-songs.sqlite3`과 `.backups/`는 이전 데이터 백업이므로 삭제하지 마세요. MySQL의 최신 데이터를 보호하려면 별도의 정기 백업이 추가로 필요합니다.

DB 서버를 단독 실행할 때는 `./start-mysql.sh`를 사용합니다. 이 스크립트는 이 Mac의 Homebrew MySQL 경로를 사용하므로 다른 컴퓨터에 그대로 복사해 실행하는 배포판은 아닙니다. 기존 `localSong` 명령에서 프로젝트의 `local-songs.sqlite3`을 대상으로 지정하면 현재 MySQL로 연결됩니다. 다른 경로의 SQLite 파일을 지정하면 해당 SQLite를 사용합니다.

가사가 저장된 곡은 PPT를 만들 수 있습니다. 저장된 권한 상태는 별도로 보존되며, 사용자 정정에 따라 두 가사 기록의 허가는 여전히 미확인입니다. UI에서 `등록된 곡`을 검색하고 곡의 상태를 확인할 수 있습니다.
